# Hub do Conhecimento — Mobile (React Native + Expo)

## Configuração
1. Edite `src/constants/api.js` e coloque a URL do domínio de produção.
2. `npm install`
3. `npx expo start`
4. Escaneie o QR Code com o **Expo Go**.

## Funcionalidades
- Login / logout com token
- Listagem com pull-to-refresh + loading + erro
- Detalhe da questão
- Busca por vestibular, ano e palavra-chave
