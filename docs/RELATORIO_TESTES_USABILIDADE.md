# Relatório de Testes de Usabilidade — Hub do Conhecimento

**Data:** [preencher]  
**Plataformas:** Web (domínio próprio) e Mobile (Expo Go)

## 1. Objetivo
Avaliar navegação, clareza, tempo de resposta e pontos de melhoria nas interfaces Web e Mobile.

## 2. Participantes (exemplo — substitua)

| ID | Idade | Perfil | Plataforma |
|----|-------|--------|------------|
| P1 | 18 | Vestibulando | Web + Mobile |
| P2 | 20 | Vestibulando | Mobile |
| P | 17 | Ensino médio | Web |

## 3. Roteiro de tarefas
1. Login
2. Listar questões
3. Abrir detalhe de uma questão
4. Buscar por vestibular / ano / palavra-chave
5. Logout

## 4. Métricas (exemplo — preencha com seus dados)

| Tarefa | Taxa conclusão | Tempo médio | Erros | Facilidade (1-5) |
|--------|----------------|-------------|-------|------------------|
| Login | 100% | 15s | 0 | 4.7 |
| Listar | 100% | 10s | 0 | 4.8 |
| Detalhe | 100% | 8s | 0 | 4.6 |
| Busca | 90% | 22s | 0.3 | 4.2 |

## 5. Feedbacks
- Pontos positivos: interface limpa, loading visível, pull-to-refresh.
- Melhorias: filtros de busca mais evidentes; mensagens de erro de rede mais claras.

## 6. Melhorias implementadas
| Problema | Solução | Status |
|----------|---------|--------|
| Filtros pouco visíveis | Botões de tipo de busca com estado ativo | Feito |
| Erro genérico de rede | Mensagem + botão Tentar novamente | Feito |
| Sem feedback de atualização | Pull-to-refresh | Feito |

## 7. Conclusão
A solução atende aos critérios de usabilidade nas duas plataformas após as correções aplicadas.
