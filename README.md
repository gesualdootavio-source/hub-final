# Hub do Conhecimento — Projeto Final

Evolução para produção: **Supabase + Vercel + domínio próprio + React Native**.

## Estrutura

```
hub-final/
├── back/          # API Express (pronta para Supabase + Vercel)
├── front/         # Frontend React + Vite (seu código original)
├── mobile/        # App React Native (Expo)
└── docs/          # Documentação técnica + relatório de usabilidade
```

## Checklist das 4 entregas

### 1. Supabase
- [ ] Projeto criado
- [ ] Schema/view criada (`docs/supabase_schema.sql`)
- [ ] `DATABASE_URL` na Vercel
- [ ] Nenhum `.env` no Git

### 2. Vercel + Domínio
- [ ] Repositório no GitHub conectado à Vercel (CI/CD)
- [ ] Variáveis de ambiente configuradas
- [ ] Domínio registrado e DNS (A/CNAME) apontando
- [ ] HTTPS ativo

### 3. Mobile
- [ ] `API_BASE_URL` apontando para o domínio de produção
- [ ] Login, listagem, detalhe e busca funcionando
- [ ] Loading + tratamento de erro de rede

### 4. Documentação e testes
- [ ] Relatório de usabilidade preenchido
- [ ] Documentação técnica
- [ ] READMEs atualizados com links reais
- [ ] Pitch 10–15 min
